# 🎭 Meme Generator

An interactive and fun web application that generates funny memes based on user input! Enter any number between 0 and 99, and discover the meme assigned to your number.

---

## ✨ Features

- 🔢 Accepts numbers from **0 to 99**.
- 🤣 Displays a unique/funny meme for each number.

---

## 🛠️ Technologies Used

- **HTML5**: For structuring the web page elements.
- **CSS3**: For styling and layout design.
- **JavaScript (ES6)**: For handling user input, logic, and dynamic meme rendering.
